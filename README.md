# Java_Day_3
This Java program is designed to calculate a student's attendance percentage based on the total number of classes conducted and the number of classes attended.

Working of the program:

It asks the user to enter the total number of classes.
It asks for the number of classes attended.
It calculates the attendance percentage using:
Attendance Percentage = (Attended Classes / Total Classes) × 100
It displays the calculated attendance percentage.
It checks the attendance percentage:
75% or above: Student is Eligible
Below 75%: Student is Not Eligible

Purpose:
The program helps students and teachers quickly determine attendance status and whether a student meets the required attendance criteria.
